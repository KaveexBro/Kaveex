================================

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

Publish with GitHub Pages:
1. Create a public repository. Recommended repository name: YOUR-USERNAME.github.io
2. Open the repository and choose Add file > Upload files.
3. Upload index.html.
4. Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a few minutes and open https://YOUR-USERNAME.github.io/

Before submitting:
- Replace any sample wording with your own accurate details.
- Check the live website on your phone.
- Take genuine screenshots of your repository, Pages settings, and published website.
